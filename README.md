# 333

Личный каталог публичных источников и ссылок на профили.

## Что сейчас есть

- вход по паролю `0910` для интерфейса;
- добавление ссылок на публичные группы;
- ручное добавление имени и ссылки на публичный профиль;
- импорт и экспорт CSV;
- поиск и удаление записей.

## Важно о текущей версии

Это статический MVP: данные хранятся только в `localStorage` браузера, а пароль находится в клиентском JavaScript. Это **не является настоящей защитой**: любой посетитель может увидеть код сайта. Не добавляйте сюда чувствительные или чужие персональные данные.

Автоматический сбор данных с Одноклассников не реализован. Используйте только разрешённый официальный API, экспорт или данные, которые вы вправе обрабатывать; сайт не обходит авторизацию, CAPTCHA и закрытые профили.

Для продакшн-версии нужно подключить серверную аутентификацию, базу данных и секреты хостинга (например, Vercel + Supabase). Пароль `0910` также рекомендуется заменить на длинный уникальный пароль.
